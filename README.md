# Communicate-Data-Findings
In this project I have obtained loan data from Prosper. After wrangling and cleaning this data I have explored it using univariate, bivariate and multivariate analysis and from this I have produced a slide show that answers the questions I was most prominently trying to answer, namely, what categories are significant in setting borrower APR and does the relationship between said category and borrower APR persist when controlling for other variables.

Findings:

What was found was that Prosper score sets the borrower APR. From this we looked at what sets the Prosper Score and found that income, debt and employment status were all found to be significant factors in determining Prosper score and hence in turn borrower APR. Following this it was found that this relationship pertains even when homeownership is controlled for.
